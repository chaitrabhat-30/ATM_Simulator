# 💳 ATM Simulator (Java Console Project)

## 📝 Description
A simple **Java console application** that simulates basic ATM operations like checking balance, depositing, and withdrawing money.  
This project demonstrates fundamental Java concepts such as **loops**, **conditional statements**, **switch-case**, and **user input handling**.

---

## 🚀 Features
- 🔐 PIN verification (3 attempts)
- 💰 Check account balance
- 💵 Deposit and withdraw money
- ⚠️ Handles invalid inputs and insufficient balance
- 👋 User-friendly console interface

---

## 🧠 Concepts Used
- Loops (`while`, `do-while`)
- Conditional statements (`if-else`)
- Switch-case structure
- Scanner class for user input
- Basic error handling

---

## 🧰 Technologies Used
- **Language:** Java  
- **Environment:** Console (Command Line Interface)
